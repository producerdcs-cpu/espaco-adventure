# 🚀 Espaço Adventure

> Onde a filosofia da palavra encontra o poder de transformar eventos.

**DcsProducer®** | Produção Criativa de Eventos

## Sobre

Plataforma de produção de eventos que une o poder filosófico da linguagem com sistemas reais de formulação de encontros aleatórios e entretenimento profissional.

## Features

- 🎲 Sistema de Aleatoriedade (4 modos)
- 🎭 6 Áreas de Entretenimento
- 📡 Formatos: Presencial, Online, Híbrido
- 💬 Filosofia da Palavra como motor criativo

## Tech Stack

- HTML5 / CSS3 / JavaScript
- ClickUp (Project Management)
- GitHub Actions (CI/CD)

## Sistemas de Aleatoriedade

| Módulo | Descrição |
|--------|----------|
| **Sorteio de Tema** | Seleção aleatória ponderada de temas filosóficos |
| **Match de Participantes** | Algoritmo de complementaridade cruzada |
| **Debate Relâmpago** | Sorteio de tema em tempo real (2-5 min) |
| **Encontro Surpresa** | Combinação cross-industry inesperada |

## Workflow de Eventos

```
Ideação → Em Formulação → Agendado → Em Andamento → Realizado → Encerrado
```
