Integração ClickUp

Configure o token e a List. Os dados ficam só no seu navegador (localStorage).

Como obter Token e List ID

1. ClickUp → Settings → Apps → API Token
2. Abra a List desejada; o número no final da URL é o List ID
3. Salve aqui e clique em Enviar

Nota: O navegador pode bloquear a chamada por CORS. Se isso acontecer, use o módulo src/core/clickup-client.js via Node ou um proxy backend. O botão tenta o envio real primeiro.
